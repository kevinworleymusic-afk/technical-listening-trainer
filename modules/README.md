# Listening Modules

This folder is reserved for module-specific listening-test logic as the trainer expands.

Planned modules include EQ / band identification, tonal attributes, noise and artifacts, spatial balance, reverberation, time alignment, imaging/localization, polarity/phase, crossover integration, bass integration, resonance detection, distortion, masking, dynamics, multichannel fault identification, and combined diagnostic listening.

Module code should ideally define the auditory manipulation being tested while relying on shared infrastructure for presentation, randomization, scoring, adaptive difficulty, logging, and analysis.
